In a sandbox the agent's shell and file tools run in a container that holds only this agent's folders: no hub data, no keys, no other agents. Memory, Records, consultations and the policy gate stay in the hub. Needs Docker and the sandbox image (Settings page). Without them a sandboxed agent gets no shell rather than running on the host.
How hard the model thinks before answering. Higher is slower and uses more of the subscription or API budget. The hub translates the level for each provider (Claude takes all of them; OpenAI tops out at extra high; Gemini at high; OpenRouter models that take a reasoning level, marked 🧠 in the OpenRouter list, at high); local models ignore it.
