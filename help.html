Agents

Talk to an agent

Click it in the list on the left, type, and press Enter. Drop a file or photo into the chat (or use the paperclip) and it reads it. Type while it's working to add a note it takes into account; the Stop button stops it.

Create an agent

  • Ask Maestro: "Make me a travel planner that's upbeat and keeps things short." It picks a model and writes the personality.
  • Or by hand: + New Agent above the agent list. Give it a name, a model and a description of its role.

New agents are ready at once. No restart is needed. If one doesn't show in the list, reload the page.

Change an agent

  • Ask Maestro: "Make Doc more concise", "Give Counsel a Record with my lease dates".
  • Or by hand: the gear (⚙) on the agent in the list opens its settings: personality, identity, Records (documents it reads every time), model, tools and shared folders.

Models

  • Change an agent's model: click the model name at the top of its chat and pick another. Next to it you can set how hard it thinks.
  • Add a way to think: Settings (⚙ at the top right) → LLM Providers, for an API key; or ask Maestro to walk you through it.
  • Costs: models marked Subscription use your Claude (or ChatGPT) plan; API models are billed per use by the provider; Local models are free and never leave this computer.

Reminders, scheduled work and files

  • Reminders and repeating tasks: ask any agent, for example "Every Monday at 9am, summarise my week". See and manage them under 📅 at the top right.
  • Files: 📁 Files at the top right uploads, downloads and browses the files your agents can read.
  • Updates: ⋯ at the top right → Update from GitHub. It installs and restarts by itself; open pages reload on their own.

Family members

Your account menu (your name at the bottom left) → Users → invite someone by email. They get their own sign-in with two-factor, and agents of their own that stay private unless you share them.

The phone app (Tailscale)

My Maestro AI only listens on this computer. The safe way to use it from your phone is Tailscale, a private network between your own devices (free for personal use). Maestro can walk you through this; the steps are:

  1. On this computer, install Tailscale and sign in. Mac: "Tailscale" from the Mac App Store. Linux: curl -fsSL https://tailscale.com/install.sh | sh then sudo tailscale up.
  2. On your phone, install the Tailscale app and sign in with the same account.
  3. Publish the hub to your devices: in a terminal, in the My Maestro AI folder, run bash scripts/tailscale-setup.sh. It prints an https address and restarts the hub by itself. (On Linux it may first ask you to run sudo tailscale set --operator=$USER once.)
  4. On your phone, open that https address, sign in, then add it to your home screen: iPhone, Share → Add to Home Screen; Android, menu → Install app.
  5. In the phone app's menu, turn on notifications and send a test notification.

When something's wrong

A Claude agent says "not signed in", "authentication" or "expired". The Claude sign-in on this computer is missing or has run out. Open a terminal, type claude and press Enter, sign in, then type /exit. Send your message again. No restart is needed. (mymaestro doctor tests the sign-in.)
An agent seems stuckPress ↻ in the chat bar to re-sync, or reload the page. Still stuck: press Stop and send the message again.
"Usage limit reached"Your plan's limit is used up until it resets. Meanwhile switch the agent's model at the top of its chat.
An API key is refusedSettings → LLM Providers: paste a fresh key from the provider's website.
A local model doesn't answerStart LM Studio or Ollama with the model loaded, or open Local models in your account menu.
The page won't load at allThe hub is stopped. In a terminal: mymaestro status, then mymaestro restart. If it still won't start, mymaestro logs shows why.
Lost the phone with your two-factor appSign in with one of your recovery codes. Or, on this computer: mymaestro reset-2fa you@example.com, then set two-factor up again under Security.
Lost the first-time setup linkmymaestro setup-link shows it again (it works until the first account exists).

If mymaestro is "not found", open a new terminal window, or use the full path: ~/.local/bin/mymaestro.

Terminal commands

Open a terminal on the computer running My Maestro AI. These work even when the hub is stopped.

mymaestro status        is it running? address, version, setup link
mymaestro restart       restart it (also: start, stop)
mymaestro logs -f       watch what it's doing
mymaestro open          open it in the browser
mymaestro update        newest version, then restart
mymaestro doctor        security and setup checks, Claude sign-in test
mymaestro backup        your data, settings and agents in one archive
mymaestro setup-link    the first-time setup link
mymaestro reset-2fa you@example.com   turn off two-factor for an account
mymaestro service install             start by itself at boot or login
