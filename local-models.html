One proxy (llama-swap) runs all local models: it starts the engine a request needs, keeps the model loaded while it is used, swaps when a different model is asked for, and unloads idle ones. Models appear to agents as local/<id>. Engines: llama.cpp for GGUF files (any model llama.cpp supports, with vision projector and speculative draft files), NInfer for .ninfer files, or any command that serves an OpenAI-compatible API on ${PORT}. Keep LM Studio's and Ollama's own servers off while this is on: one scheduler per GPU.

Proxy and engines

Start and Stop act on the proxy only; models load on first request. Apply config rewrites the proxy's config file after edits (the proxy watches it; a port change needs Restart). Build llama.cpp compiles llama-server for this machine in the background (5 to 15 minutes; CUDA when present, Homebrew on a Mac). Refresh hub model list makes new local/… ids appear in every model picker.
