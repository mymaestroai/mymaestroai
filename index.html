💬 Discussion Types

Free-flowing: You participate alongside agents. Send messages anytime.

Autonomous: Agents discuss on their own. You set the topic and watch.

Moderated: A designated summarizer synthesizes after each round.

📋 Context Modes

Full history: All agents see everything. Most coherent but slower.

Summary only: Agents only see the latest synthesis. Faster, less tokens.

Last N: Rolling window of recent messages. Balance of speed and context.

🎯 Tiger Team Modes

Roundtable: All agents speak each round, round-robin style.

Led: One leader agent drives the conversation, consulting others via consult_agent until satisfied.
